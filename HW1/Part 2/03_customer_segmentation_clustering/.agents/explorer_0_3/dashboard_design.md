## 1. Executive Summary & Dashboard Architecture

The Customer Segmentation Admin Dashboard is an enterprise-grade, interactive React single-page application (SPA) designed to bridge machine learning clustering outputs with business intelligence decision-making. Built on modern web standards (React 18+, Vite 5+, TypeScript, Tailwind CSS, Lucide Icons, and Recharts), the dashboard provides exploratory data analysis, multi-dimensional cluster visualization (2D and 3D), statistical distribution profiling, marketing persona formulation, model diagnostic benchmarking, and real-time autoresearch hill-climbing inspection.

### 1.1 Key Architectural Principles
1. **Decoupled Yet Tightly Contracted**: The dashboard consumes static and dynamically generated JSON artifacts (`pipeline_output.json` and `autoresearch_output.json`) produced by the Python ML pipeline (`run_pipeline.py` and `autoresearch.py`).
2. **Zero-Failure Standalone Resilience**: Ships with an embedded, full-fidelity default dataset (`defaultData.ts`). If the Python pipeline has not been executed or JSON files are unavailable during offline testing, the dashboard gracefully falls back to default data, ensuring `npm run build` and automated render tests always pass with 100% reliability.
3. **High-Performance Multi-Dimensional Visualization**: Supports 2D projections (Annual Income vs Spending Score, Age vs Spending Score, Age vs Annual Income, PCA 1 vs PCA 2) and an interactive 3D cluster scatter visualizer with orbit rotation, zoom, centroid markers, and hover tooltips.
4. **Actionable Business Intelligence**: Translates mathematical cluster centroids and demographic distributions into 5 distinct customer persona profiles complete with strategic marketing recommendations, channel targeting, and ROI ratings.
5. **Autoresearch Diagnostic Transparency**: Displays the benchmark research paper citation, baseline vs optimized metrics, hyperparameter mutation logs, and iteration convergence curves generated by the hill-climbing optimizer.
