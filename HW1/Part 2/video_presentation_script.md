Master Video Presentation Guide - Data Mining HW1 Part 2

This workspace has six projects, numbered 00 through 05. Each one has its own standalone script file at <project folder>/VIDEO_SCRIPT.md, written to be read as a cheat sheet while recording, plain text, no deep dive, just the most important file or two per project plus the code to point at.

00 Dynamic TODO Workspace
File: 00_dynamic_todo_workspace/VIDEO_SCRIPT.md
Command: make 00 (or ./run --00)
Task management app with SQLite persistence. Next.js, React, TypeScript, Framer Motion.

01 NYC Taxi Trip Prediction
File: 01_nyc_taxi_trip_prediction/VIDEO_SCRIPT.md
Command: make 01 (or ./run --01)
Predicts NYC taxi trip duration from pickup and dropoff coordinates. Python, XGBoost, Scikit-Learn, FastAPI, Vite and React.

02 Nano LLM Transformer
File: 02_nano_llm_transformer/VIDEO_SCRIPT.md
Command: make 02 (or ./run --02)
A causal language model built from scratch in pure PyTorch, with RoPE, SwiGLU, RMSNorm, and grouped query attention. FastAPI admin dashboard.

03 Customer Segmentation Clustering
File: 03_customer_segmentation_clustering/VIDEO_SCRIPT.md
Command: make 03 (or ./run --03)
Groups mall customers into personas using K-Means, DBSCAN, and Agglomerative clustering, with an automated hyperparameter search. React dashboard.

04 Associative Pattern Mining Studio
File: 04_associative_pattern_mining/VIDEO_SCRIPT.md
Command: make 04 (or ./run --04)
Market basket association rule mining with FP-Growth on retail transaction data. Flask dashboard on port 5050.

05 Data Science Skills Lab
File: 05_data_science_skills_lab/VIDEO_SCRIPT.md
Command: make 05 (or ./run --05)
48 agent skills demonstrated on the IBM Telco Churn dataset, with an independent verification harness that recomputes every headline number from the raw CSV. FastAPI backend, React frontend.

How to use this for recording
Open the VIDEO_SCRIPT.md for the project you are recording next to your terminal and browser. Run the make command listed, read the intro lines out loud, switch to the code file listed and reference the code excerpt already pulled into the script, then do the live demo steps, then read the wrap up line.
